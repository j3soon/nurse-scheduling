## Free Services

The hosted parts of this project rely on free plans provided by:

- [Sentry](https://sentry.io/), which tracks errors on its OSS plan.
- [Netlify](https://www.netlify.com/), which hosts the frontend on its free plan.
- [Oracle Cloud](https://www.oracle.com/cloud/), which hosts the optimization servers on its free tier.
- [GitHub](https://github.com/), which hosts the source code, with GitHub Actions running the CI.
- [Coderabbit](https://coderabbit.ai/), which reviews pull requests on its free plan.
- [Greptile](https://www.greptile.com/), which assists with codebase questions and pull request review on its free plan.
- [E2B](https://e2b.dev/), which provides cloud sandboxes on its free plan.
- [Codecov](https://codecov.io/), which tracks test coverage.
- [Google Analytics](https://analytics.google.com/), which tracks visits to the app and documentation sites.
